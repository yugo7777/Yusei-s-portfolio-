# project-01 の資料フォルダ

ここに `project-01` の制作資料(PDF)を配置してください。

想定しているファイル名(そのまま置けばサイトからリンクされます):

- `idea.pdf` — アイデア書
- `planning.pdf` — 企画書
- `prototype.pdf` — 試作書(プロトタイプ検証レポート)

ファイル名を変える場合は `projects/project-01.html` 内の該当する `href` も合わせて書き換えてください。

PDF以外(Word, PowerPoint, 画像など)を置く場合も、リンク先の拡張子を実際のファイルに合わせてください。

# project-01 のスクリーンショット・サムネイル画像フォルダ

- スクリーンショットを配置し、`projects/project-01.html` の `#gallery` 内にある
  `<div class="gallery-item">screenshot-01.png</div>` を `<img>` タグに差し替えてください。

  ```html
  <div class="gallery-item">
    <img src="../assets/images/project-01/screenshot-01.png" alt="スクリーンショット1" style="border-radius:10px;">
  </div>
  ```

- Play映像を `<video>` タグで直接埋め込む場合、`thumbnail.jpg` をこのフォルダに置くと
  再生前のサムネイル(poster)として使えます。
